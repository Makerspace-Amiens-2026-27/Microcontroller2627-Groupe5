# Journal du 2026-11-24

## Résumé

Lors des séances précédentes, chaque module avait été testé séparément. Aujourd'hui, nous avons fait fonctionner ensemble l'écran, le joystick, le bouton et le buzzer. Nous avons aussi installé KiCad sur le PC d'Ajaz, importé la bibliothèque du cours et commencé le schéma électrique de la carte (une Game Boy). Nous avons travaillé à deux sur un maximum de tâches.

## 1. Test de l'ensemble des modules

### Matériel

- Carte : XIAO ESP32S3
- Écran : TFT 3,5 pouces ST7789, tactile I2C, utilisé en SPI (la partie tactile n'est pas câblée pour l'instant)
- Joystick analogique avec bouton (SW)
- Bouton (module)
- Buzzer actif (module vendu monté)
- Breadboard et fils

### Câblage

**Écran (SPI)**

| Broche écran | Broche XIAO ESP32S3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| CS | GND |
| RESET | D7 |
| DC | D8 |
| SDI (MOSI) | D10 |
| SCK | D9 |
| LED | 3V3 |

**Joystick**

| Broche module | Broche XIAO ESP32S3 |
|---|---|
| GND | GND |
| +5V | 3V3 (jamais 5V) |
| VRx | D0 |
| VRy | D1 |
| SW | D2 |

**Bouton**

| Broche module | Broche XIAO ESP32S3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| S | D5 |

**Buzzer** (module à deux broches utiles : pas de VCC côté composant, seulement S et GND)

| Broche module | Broche XIAO ESP32S3 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| S | D3 |

## 2. KiCad

### Installation et bibliothèques

- Installation de KiCad 10.0 sur le PC d'Ajaz.
- Import de la bibliothèque fournie pour le cours, afin de garder une uniformité entre tous les projets microcontrôleur. L'import se fait via le gestionnaire de bibliothèques de symboles et d'empreintes (configuration des chemins).

### Problème rencontré avec la bibliothèque

La bibliothèque fournie était mal rangée. En suivant la procédure du cours, l'import ne fonctionnait pas tel quel : il fallait faire des manipulations supplémentaires pour arriver au même résultat. Nous l'avons signalé à l'enseignant pour qu'il corrige l'organisation de la bibliothèque. Nous avons aussi aidé un groupe qui n'arrivait pas à passer cette étape.

### Début du schéma

Composants posés :

- 1 XIAO ESP32S3
- 2 boutons
- 1 joystick
- 1 connecteur pour l'écran

Liaisons réalisées : entre l'ESP32 et le connecteur de l'écran.

Conventions utilisées : symboles d'alimentation et labels pour nommer chaque connexion. Aucune valeur de composant n'est encore choisie (résistances de pull-up, condensateurs de découplage, etc.).
